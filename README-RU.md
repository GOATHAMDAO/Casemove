# Casemove — простая инструкция по установке и запуску

Casemove — программа для работы с инвентарём Counter-Strike 2 и Storage Units: просмотра предметов, переноса между хранилищами, управления несколькими Steam-профилями и создания Excel-отчётов.

Эта инструкция написана для Windows-пользователя без опыта работы с кодом. Не нужно устанавливать CS2, Git или VS Code.

## Что понадобится

- компьютер с **Windows 10 или Windows 11, 64-bit**;
- стабильный интернет;
- доступ к своему Steam-аккаунту;
- приложение Steam на телефоне, чтобы подтвердить вход по QR-коду;
- 3–5 ГБ свободного места на диске.

> Никому не отправляйте файлы из папки `%APPDATA%\casemove`, QR-коды Steam, refresh-токены или API-ключи. Это личные данные вашего профиля.

## Как запустить программу сейчас

Сейчас готового установщика `.exe` нет. Программу нужно скачать как ZIP-архив и запустить из исходников по инструкции ниже.

### Шаг 1. Скачайте проект

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code**.
3. Нажмите **Download ZIP**.
4. Дождитесь загрузки файла, обычно он находится в папке «Загрузки».
5. Нажмите на ZIP-файл правой кнопкой мыши → **Извлечь всё…**.
6. Выберите простую папку, например `C:\Casemove`, и нажмите **Извлечь**.

Не запускайте программу прямо из ZIP-архива. Сначала обязательно извлеките все файлы.

### Шаг 2. Установите Node.js

Node.js нужен только для запуска версии из исходников.

1. Откройте [nodejs.org](https://nodejs.org/).
2. Скачайте версию с пометкой **LTS** для Windows. Для этого проекта подходит Node.js **22 LTS или новее**.
3. Запустите скачанный установщик.
4. Нажимайте **Next** и оставляйте предложенные настройки без изменений.
5. В конце нажмите **Finish**.
6. Если у вас были открыты окна PowerShell или Командной строки, закройте их и откройте заново.

Git, Python, Visual Studio Code и CS2 устанавливать не нужно.

### Шаг 3. Установите файлы, нужные программе

1. Откройте извлечённую папку Casemove.
2. Нажмите правой кнопкой мыши на пустом месте в папке.
3. Выберите **Открыть в терминале** или **Открыть PowerShell здесь**.
4. В появившемся окне вставьте команду:

```powershell
npm ci
```

5. Нажмите Enter и дождитесь окончания. Первый раз это может занять несколько минут.
6. Когда снова появится строка с путём к папке, закройте окно терминала.

Если команда `npm ci` сообщила об ошибке, выполните вместо неё:

```powershell
npm install
```

Не закрывайте терминал, пока команда выполняется. Сообщения с названиями пакетов и проценты загрузки — это нормально.

### Шаг 4. Запустите программу

1. В папке Casemove дважды нажмите `Start-Casemove-Dev.bat`.
2. При первом запуске подождите 1–3 минуты: приложение собирает свои файлы.
3. Должно открыться окно Casemove со страницей входа.

Если не хотите видеть чёрное окно запуска, используйте `Launch-Casemove-Dev.vbs`. Он запускает ту же программу в фоне.

## Первый вход в Steam

1. Откройте Casemove.
2. Выберите вход по QR-коду.
3. Откройте мобильное приложение Steam.
4. Отсканируйте QR-код и подтвердите вход на телефоне.
5. Подождите, пока статус подключения к CS2 станет **Connected**.

Для работы со Storage Units Casemove подключается к серверу CS2. Это может занимать некоторое время, особенно при первом входе.

Если программа предлагает сохранить сессию, это позволяет потом переключаться между вашими профилями без повторного QR-входа. Сессия хранится только на этом компьютере в зашифрованном локальном хранилище.

## Как пользоваться основными разделами

### Inventory

- Показывает предметы текущего аккаунта и Storage Units.
- Кнопка `↻` обновляет инвентарь Steam.
- При открытии Inventory программа загружает содержимое всех Storage Units. Не закрывайте её, пока видите `Loading storages…`.
- Кнопка **Export all to Excel** создаёт общий Excel-файл по всем сохранённым Steam-профилям.

Excel-отчёт включает:

- общее количество предметов (`Total`);
- количество в PriceEmpire-портфелях, если настроен API-ключ;
- `Add / Remove`: положительное число нужно добавить в PriceEmpire, отрицательное — убрать;
- отдельное количество в Storage Units;
- активный основной Steam-профиль, затем остальные сохранённые профили.

Готовый Excel-файл открывается в папке **Загрузки** Windows.

### Storage Units

- **Transfer | From** — переносит предметы из хранилища в обычный инвентарь.
- **Transfer | To** — переносит предметы из обычного инвентаря в выбранное хранилище.
- **Transfer | Saved account** — создаёт трейд-предложение для другого сохранённого аккаунта.

Предметы с трейд-локом, находящиеся в Storage Units или недоступные для обмена, не появятся в списке предметов для трейда. Это нормальное ограничение Steam.

### Несколько Steam-профилей

1. Откройте список сохранённых профилей.
2. Войдите в каждый нужный аккаунт по QR-коду и разрешите сохранить сессию.
3. После этого общий Excel-экспорт сможет собрать данные из всех этих профилей.

Не удаляйте сохранённый профиль, если хотите включать его в общий экспорт.

### PriceEmpire

PriceEmpire необязателен. Он нужен только для сравнения Excel-отчёта с вашими портфелями.

1. Откройте **Settings** → **Market API keys**.
2. Вставьте новый API-ключ PriceEmpire в поле `PriceEmpire API key`.
3. Нажмите **Save**.
4. При необходимости добавьте название портфеля в `Ignore PriceEmpire portfolios`, чтобы его предметы не учитывались в отчёте.
5. Создайте экспорт из Inventory.

Ключ не отображается после сохранения и не добавляется в файлы Excel, GitHub или исходный код. Если ключ был кому-то отправлен, отзовите его в PriceEmpire и создайте новый.

## Частые проблемы и решения

### «Node.js is not installed» или `npm` не найден

1. Установите Node.js LTS с [nodejs.org](https://nodejs.org/).
2. Закройте все окна терминала.
3. Перезагрузите компьютер, если ошибка осталась.
4. Откройте папку Casemove и снова запустите `Start-Casemove-Dev.bat`.

### «Dependencies are missing»

В папке Casemove откройте терминал и выполните:

```powershell
npm ci
```

После завершения снова запустите `Start-Casemove-Dev.bat`.

### Программа не открывается или сразу закрывается

- Убедитесь, что проект извлечён из ZIP-архива.
- Проверьте, что в папке есть `package.json` и `Start-Casemove-Dev.bat`.
- Запустите `Start-Casemove-Dev.bat` двойным щелчком, а не сам Electron.
- Проверьте, не заблокировал ли файл антивирус. Разрешайте запуск только файлов из доверенного репозитория.
- Для просмотра ошибки откройте терминал в папке проекта и выполните `npm run start`.

### Долго висит `Loading storages…`

Casemove запрашивает содержимое каждого Storage Unit у серверов CS2 по очереди. Хранилища с большим числом предметов и нестабильный интернет увеличивают ожидание.

- Не закрывайте программу во время загрузки.
- Проверьте интернет.
- Подождите несколько минут и затем нажмите `↻`, если загрузка завершилась ошибкой.
- Не запускайте одновременно несколько копий Casemove для одного аккаунта.

### После нажатия Export all to Excel не появляется файл

- Проверьте папку **Загрузки** Windows.
- Убедитесь, что хотя бы один Steam-профиль сохранён в Casemove.
- Дождитесь подключения текущего профиля к CS2.
- Если PriceEmpire не настроен, Steam-часть отчёта всё равно должна создаться, а колонки PriceEmpire останутся пустыми.

### PriceEmpire-колонки пустые

- Откройте **Settings** → **Market API keys**.
- Убедитесь, что ключ сохранён.
- Проверьте, что ключ имеет доступ к Portfolio API.
- Убедитесь, что нужный портфель не указан в поле игнорируемых портфелей.

### Steam снова просит вход

Сохранённая сессия Steam может истечь или быть отозвана Steam. Войдите в этот профиль по QR-коду ещё раз и сохраните обновлённую сессию.

## Безопасность и личные данные

- Casemove не требует пароль Steam в README, Excel-файле или GitHub.
- Вход подтверждается в официальном мобильном приложении Steam.
- Сохранённые Steam-сессии и API-ключи находятся только на вашем компьютере.
- Не публикуйте `%APPDATA%\casemove`, файлы `.env`, сертификаты, логи или скриншоты с ключами.
- Перед передачей проекта другому человеку отправляйте ссылку на репозиторий или свежий ZIP с GitHub, а не свою рабочую папку.

## Как обновить программу

Самый простой безопасный способ:

1. Скачайте свежий ZIP с GitHub.
2. Извлеките его в новую папку, например `C:\Casemove-new`.
3. Выполните в новой папке `npm ci`.
4. Запустите `Start-Casemove-Dev.bat`.

Сохранённые Steam-профили и API-ключи не лежат в папке проекта, поэтому при обновлении исходников они сохраняются локально.

## Для разработчика: создание установщика Windows

Обычному пользователю этот раздел не нужен. В папке проекта выполните:

```powershell
npm run make:win
```

Готовый установщик появится по пути:

```text
out\make\squirrel.windows\x64\Casemove-Setup.exe
```

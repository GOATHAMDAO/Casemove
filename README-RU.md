# Casemove — руководство пользователя и FAQ

Casemove помогает просматривать инвентарь CS2 и содержимое Storage Units, объединять одинаковые предметы, переносить предметы между инвентарём и хранилищами и работать с несколькими сохранёнными Steam-профилями.

## Скачивание и запуск без установщика

1. Скачайте исходный код через **Code → Download ZIP** на GitHub или клонируйте репозиторий через Git.
2. Распакуйте архив в обычную папку, например `C:\Casemove`.
3. Установите [Node.js LTS](https://nodejs.org/) 22-й версии или новее.
4. В папке проекта дважды нажмите `Start-Casemove-Dev.bat`.
5. При первом запуске зависимости будут нужны в папке проекта. Если появится сообщение о них, откройте PowerShell в этой папке и выполните `npm ci`, затем снова запустите `.bat`.

Требуются Windows 10/11 x64, [Node.js LTS](https://nodejs.org/), интернет-соединение и Steam Guard на телефоне для входа по QR-коду. Git и VS Code не обязательны; CS2 устанавливать тоже не нужно.

## Как запустить приложение

После подготовки папки проекта:

1. Дважды нажмите `Start-Casemove-Dev.bat`.
2. При первом запуске подождите 30–60 секунд, пока Electron соберёт приложение и откроется окно входа.
3. Войдите в Steam по QR-коду и дождитесь статуса **Connected**.
4. После подключения откройте **Overview** — приложение загрузит инвентарь и доступные Storage Units.

Используйте файлы только из этого репозитория или от доверенного автора. Не запускайте неизвестные `.bat` или `.vbs` файлы, полученные из других источников.

## Первый вход

1. В Casemove выберите вход по QR-коду.
2. Откройте приложение Steam на телефоне и отсканируйте QR-код.
3. После успешного входа можно сохранить сессию и затем быстро переключаться между своими профилями.

Сохранённый профиль не передаётся другим пользователям и не загружается в GitHub. Не копируйте и не отправляйте папку `%APPDATA%\casemove`.

## Ярлык и панель задач

Для запуска без окна `cmd` используйте `Launch-Casemove-Dev.vbs`: он запускает тот же проект в фоне. Создайте на него ярлык на рабочем столе, при необходимости задайте значок `assets\icon.ico`, затем закрепите именно этот ярлык на панели задач.

Не закрепляйте отдельный значок с названием **Electron**: это технический процесс, и такой ярлык может открыть пустое окно Electron вместо Casemove.

## Функции приложения

### Профили Steam

- Войдите по QR-коду и при необходимости сохраните сессию.
- Добавьте несколько своих профилей и переключайтесь между ними кнопкой с галочкой у сохранённого профиля.
- В списках перевода используются логины, чтобы не путать аккаунты с одинаковыми никами.

### Overview

- Автоматически загружает предметы из обычного инвентаря и Storage Units.
- Показывает общее количество, количество в инвентаре и количество в хранилищах.
- Показывает распределение предметов по категориям.
- Кнопка **Export CSV** выгружает простой CSV с названием предмета и общим количеством.

### Inventory

- Показывает предметы из инвентаря и всех загруженных Storage Units в одном списке.
- Одинаковые предметы объединяются, включая предметы из нескольких хранилищ; `QTY` показывает общую сумму.
- Предметы с трейд-локом отображаются отдельно от доступных предметов. Одинаковые заблокированные предметы объединяются между собой, а в **Tradehold** виден диапазон разблокировки.
- Доступны поиск, фильтры, сортировка, отображение Storage Unit, трейд-холда, количества и возможности переноса.
- Кнопка `↻` обновляет данные со Steam.

### Transfer | From

- Выберите один или несколько Storage Units.
- Найдите нужный предмет, укажите количество и переместите его из хранилища в обычный инвентарь.
- Если одинаковый предмет есть в нескольких выбранных хранилищах, приложение показывает одну строку с суммой и распределяет перенос между ними.

### Transfer | To

- Выберите Storage Unit.
- Выберите предметы из обычного инвентаря, укажите количество и поместите их в хранилище.
- После подтверждения Steam данные обновляются автоматически; при необходимости используйте `↻`.

### Transfer | Saved account

- Выберите сохранённый аккаунт-получатель и сохраните его Steam trade link.
- Нажмите **Refresh profiles**, чтобы проверить актуальное свободное место в инвентаре получателя.
- В списке видны только предметы, которые разрешено отправить прямо сейчас: предметы из Storage Units, с трейд-холдом и непередаваемые предметы скрыты.
- Выберите количество каждого предмета, создайте трейд-предложение и подтвердите его в Steam Guard, если Steam потребует подтверждение.

### Внешний вид

- Переключатель внизу бокового меню меняет светлую и тёмную тему.
- Настройка сохраняется локально для текущего пользователя Windows.

## FAQ

### Нужны ли Node.js, Git или VS Code?

Node.js нужен, потому что приложение запускается из исходников без установщика. Git нужен только для клонирования репозитория — вместо этого можно скачать ZIP. VS Code не нужен.

### Где хранятся мои сохранённые Steam-профили?

Локально в профиле Windows, в данных приложения. Они не хранятся в репозитории GitHub и не передаются другим пользователям вместе с установщиком.

### Почему предметы в трейд-холде видны в Inventory?

Они всё ещё принадлежат аккаунту и занимают место в инвентаре, но временно не могут участвовать в трейде. В колонке **Tradehold** показано оставшееся время. Они не смешиваются с доступными предметами: одинаковые заблокированные предметы объединяются только между собой, с общей `QTY` и диапазоном дат блокировки.

### Почему предмет есть в Inventory, но отсутствует в Transfer | Saved account?

В это меню попадают только предметы, которые можно отправить прямо сейчас. Storage Units, предметы в трейд-холде и непередаваемые предметы намеренно скрываются.

### Почему в Inventory отображается несколько Storage Units?

Casemove загружает предметы из всех доступных Storage Units. Если один и тот же предмет есть в нескольких из них, его количество суммируется, а в колонке **Storage** перечисляются источники.

### Как обновить список предметов после переноса?

Нажмите кнопку обновления `↻` в нужном разделе или снова откройте Overview. Steam может обновить данные с небольшой задержкой после операции.

### Почему приложение просит подтвердить действие в Steam Guard?

Steam требует подтверждение некоторых торговых действий. Откройте приложение Steam на телефоне и подтвердите операцию как обычно.

### Можно ли отправить Casemove другу?

Да. Отправьте ссылку на репозиторий или ZIP без `.env`, сертификатов, логов и папки `%APPDATA%\casemove`. Другу понадобится Node.js, после чего он выполнит `npm ci` и запустит `Start-Casemove-Dev.bat`.
